# 📊 Sentiment Analysis Project

A comprehensive Data Analysis project built with Python to clean, analyze, and visualize sentiment/comments data, featuring interactive geographical maps.

---

## 🛠️ Tools & Technologies Used
* **Python** 🐍
* **Pandas:** For data manipulation, cleaning, and filtering.
* **Seaborn & Matplotlib:** For advanced data visualizations and correlation heatmaps.
* **Plotly:** For building interactive world maps to visualize data distribution geographically.

---

## 🚀 Project Overview
In this project, I focused on:
1. **Data Cleaning & Manipulation:** Handling missing values and preparing the dataset for analysis.
2. **Data Visualization:** Creating insightful statistical graphs to understand the data trends.
3. **Interactive Mapping:** Designing an interactive world map (`Plotly`) to display the data distribution across different countries.

---

## 📂 File Structure
* `Sentiment.ipynb`: The main Jupyter Notebook containing all the data analysis, cleaning steps, and visualizations.
